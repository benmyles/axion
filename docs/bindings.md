# Learning which object causes an outcome

The two objects first move together. The animal can learn what follows each bearing while still having no evidence about which object caused the change. It can then compare predictions for potential experiments, physically choose one, and update its source contacts from the result. In the original interview question about food and water exchanging places, the released individual scored **128/128**. Its motion-only predecessor scored **0/128** on the same streams. Human participants used previously learned relational structure to adapt to new circumstances in a November 2026 study. In a separate experiment, preschoolers preferentially explored a toy whose mechanism remained confounded, and sometimes separated the variables during play. These results motivated measuring uncertainty before an intervention and testing whether an animal can choose evidence that resolves it. The CUDA experiment offers a small, exactly specified space of possible mechanisms. ## Observations and local plasticity

Each action-sensitive field contains two competing input pathways per output object. A pathway has sixteen two-bit synapses between departure and arrival assemblies. These use the visual rule that evolved in an earlier experiment. Each pathway also has two bits of support. Its previous prediction is available before the arrival. A separate inherited transition table updates support when the observation is missing, consistent, contradictory or partially overlapping. Other genes determine competition between the pathways and the strength of an exploratory motor response to disagreement. Mutation can change all three programs. Four action fields, their programs and the trace of an outstanding experiment occupy **104 bytes**. [Source credit and projection](../src/binding.cuh) · [Visual rule](recollection.md)

The physical nursery initially presents eight movements in which both objects are at the same bearing. There are four possible experiments. In the aliased environment even a visibly different arrangement can give the same prediction under both hypotheses. The diagnostic arrangement separates the two predicted effects. A source reversal changes which input controls each output. The animal receives before-and-after sensory activity from the action it tried. The scorer then tests fresh arrangements. The payoff used to breed a rule measures the two predictions and appropriate initial silence. Choosing the informative experiment earns no direct bonus. ## A separate spoken test

An external experimenter generated different laws and four previously unseen action sounds. The experimenter used the public text interface to demonstrate the confounded movements, offer four initial arrangements and deliver the actual arrival for the one the animal selected. The animal chose a physical arrangement before receiving the outcome. In eight streams it stayed silent on all 64 probes where two possible explanations gave different answers. It chose the informative arrangement on 32/32 first encounters and 32/32 reversals. The full speaking pair made 256/256 correct held-out reports in each phase. It also made 128/128 correct reports after 32-action sequences and 128/128 on order-sensitive pairs. None of these sequences was shown during teaching. [Aliased interviews](bindings/spoken-aliased.csv) · [Independent partitions](bindings/spoken-independent-transfer.csv) · [Random exploration](bindings/spoken-random.csv) · [Frozen source contacts](bindings/spoken-frozen.csv)

The source contacts also control physical visual access. In an exchange, a request about food can open the water aperture. If both mechanisms remain plausible the witness can open both. The journal records the requested output, opened apertures and the activity actually obtained from each. A covered or absent view can only supply a reinstated activity from that individual’s visual memory. Hypothetical results do not overwrite the physical observation. Multiple actions compose as Boolean relations between the two pairs of sensory assemblies. This representation models one input source per output and can retain uncertainty between sources. Arbitrary interactions requiring both inputs jointly remain beyond it.

We measured that limit using rearranged addition and exclusive-or tables. Both input bearings affect each output. Even after four passes over every possible initial arrangement, the speaking witness was silent on **512/512** questions. It also scored **0/128** on the earlier shared location and the location two sightings back. These failures identify specific missing representations despite successful exchange and causal-role learning. [Joint interactions](bindings/joint-interaction.csv) · [Multi-episode questions](bindings/transfer.csv)

We also asked about exchanges in two living habitats. A separate scorer compared the answer to the other resource's measured directional currents. The speaker gave 128/128 correct exchange answers in each habitat. On 184 of these 256 questions the two resources had different bearings. When following residents at tick 196,608 and beyond, the pair answered all 512 current, last-seen, rotated and exchanged-location questions correctly. The observation record time-stamps physical currents against the number of previously answered turns.
