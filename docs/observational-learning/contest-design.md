# Reciprocal access to visual information

The first three unseeded founder populations were exploratory. Their results motivated six additional independent population seeds fixed before the new runs began. The seeds are 73453, 106619, 146381, 193939, 242927 and 299171.

Each 128 × 128 shoal develops for 16,384 ticks with food, water, clay, cord and ordinary visual experience. At the split, two heritable neutral marks partition its residents. Both sets can move, learn, spend energy, reach, breed and change the same substrates. Three copies begin with identical bodies, learned contacts, energy, occupied sites and material. In the first, mark 1 sees light from the actual moving source and mark 2 sees the endpoint of a different source on the same bed. The second exchanges those assignments. Both marks receive the real event in the sham. There is no nursery transplant, English tutor, external fitness function or adaptive choice of endpoint.

The primary outcome at tick 65,536 is the fraction of living residents bearing mark 1 in the first copy minus that fraction in the second copy. A positive difference favors informative sight. Report every founder, direction and terminal count along with the sham. Report total extinction separately if either fraction is undefined. The experimental unit is an independently founded watershed. The number of descendants or feeding events within a watershed does not increase that sample size.

A secondary test asks whether descendants born after tick 24,576 can intercept unfamiliar releases after watching individual transfers, relative to the same unchanged tissue before observation. Selection and confirmation of the sampled circuit use different random layouts. This separates ecological survival from a specific behavioral explanation for it.
